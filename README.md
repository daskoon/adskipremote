# Project Summary: AdSkip Remote for WearOS / Watch

## 1. Overview & Concept
Wearable companion application for smartwatches enabling users to instantly skip YouTube ads and control video playback from their wrist.

- **Primary Tech Stack:** Android WearOS, Kotlin, Accessibility Service
- **Project Rating:** 8.2/10
- **Estimated Completion:** 80%
- **Repository:** [adskipremote](https://github.com/daskoon/adskipremote)

## 2. Current State
Extensive Android codebase with 470+ files, Gradle builds, accessibility service listeners, and watch UI controllers.
